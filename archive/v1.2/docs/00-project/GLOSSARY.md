# Glossary

- **Acceptance:** independent evidence-backed decision that approved criteria are met.
- **Authority:** source entitled to define project truth for a subject.
- **Blast radius:** systems, data, assets, users, tools, and workflows a change may affect.
- **Evidence pack:** immutable record of what was tested, where, how, and with what result.
- **Freeze:** accepted state protected by change control.
- **Golden path:** approved way to implement a recurring capability.
- **Implementation lease:** human-activated, time-limited, task/review-hashed and Git-base-bound write authority.
- **Implementation seal:** human-created record of exact changed paths and deterministic diff digest that closes agent write authority.
- **Rigor:** strength of specification, review, and evidence required by risk.
- **Spike:** bounded experiment that reduces a specific uncertainty without becoming production by default.
