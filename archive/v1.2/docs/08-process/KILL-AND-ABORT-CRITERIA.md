# Kill and Abort Criteria

Every R2+ feature defines conditions under which it is canceled, reduced, or redesigned. Every major milestone defines abort/replan conditions.

Examples:

- Dynamic cargo physics is killed or redesigned if the required four-player network workload cannot meet the approved bandwidth/frame budget after the bounded spike budget.
- A vertical slice is replanned if the core voyage loop remains unclear or unengaging after three validated iterations.
- A procedural crisis system is paused if it creates unrecoverable softlocks above the accepted threshold.

Kill criteria protect the project from infinite rescue work and sunk-cost reasoning.
