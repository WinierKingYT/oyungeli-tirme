# Asset Production Standard

Each asset family defines source format, units, axes, naming, folder, pivot, topology, UV, material, texture, collision, LOD, skeleton, animation, compression, memory, platform variants, import preset, validator, provenance, and acceptance scene.

Binary engine assets are changed through the engine or approved pipeline, not text-editing tools. Source assets remain traceable. Generated assets are candidates until in-engine, performance, deformation/collision, and packaged-build checks pass.
