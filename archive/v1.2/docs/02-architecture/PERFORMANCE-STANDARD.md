# Performance Standard

No performance claim is valid without platform, build configuration, workload, content scale, tool, sample duration, and metric.

Establish baselines before high-risk changes. Gate CPU, GPU, memory, allocations, streaming/loading, asset residency, and network budgets. Track both absolute budget and regression delta.

Optimize measured bottlenecks while preserving correctness. A profiler screenshot without reproducible workload and revision is insufficient evidence.
