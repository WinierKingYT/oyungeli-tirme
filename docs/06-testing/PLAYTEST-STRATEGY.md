# Playtest Strategy

Playtests answer design hypotheses, not technical correctness alone.

Each session records participant profile, build revision, scenario, hypothesis, observation method, success/kill threshold, confounds, raw notes, and decision. Do not ask leading questions or convert one anecdote into a global decision.

Core-loop priority questions:

- Can players understand what to do without persistent HUD instruction?
- Does cargo handling create cooperation or only friction?
- Do crises create choices rather than chore stacking?
- Can players recover from partial failure?
- Are quiet-time activities optional and valuable?
