# Judgement Gaps — decisions the owner makes

> The agent asks instead of deciding on anything listed here. Fill values as they are decided; an empty row means "ask".

| Tone | How much slapstick vs. tension? | | |
| Feel | Reference games for how heavy things should feel | | |
