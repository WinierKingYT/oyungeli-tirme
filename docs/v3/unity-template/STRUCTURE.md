# Unity project structure (v3)

Apply once per Unity project (Unity 6 LTS recommended). The agent creates folders and asmdefs **through Unity MCP / Editor**, so `.meta` files are generated by Unity.

## Editor settings (Project Settings)
- Editor → Asset Serialization: **Force Text**
- Version Control → Mode: **Visible Meta Files**
- Player → Api Compatibility: .NET Standard 2.1 (default)
- Commit `ProjectSettings/ProjectVersion.txt` (pins the editor version)

## Folders
```
Assets/
  _Project/
    Scripts/
      Core/                 Game.Core.asmdef        (pure C#; no UnityEngine where possible)
      <Feature>/            Game.<Feature>.asmdef   (references Core)
      Editor/               Game.Editor.asmdef      (Editor only; references features)
    Data/                   ScriptableObject configs (tunables)
    Prefabs/
    Scenes/
    Art/ Audio/ Materials/ VFX/
  _Prototype/               Game.Prototype.asmdef   (throwaway; nothing references it)
  Tests/
    EditMode/               Game.Tests.EditMode.asmdef  (Editor platform; refs Core + features; nunit)
    PlayMode/               Game.Tests.PlayMode.asmdef  (refs features; nunit)
game/  memory/  evals/  reviews/     (v3 design files, outside Assets)
```

## Assembly rules
- Dependency direction: Feature → Core. Editor → Feature. Tests → anything. Prototype → anything; **nothing → Prototype**.
- No circular references; if two features need each other, extract the shared contract to Core.
- `autoReferenced: false` for feature assemblies (explicit references only).

## asmdef examples (created via Editor/MCP, shown for content)
```json
{ "name": "Game.Core", "rootNamespace": "Game.Core", "references": [], "autoReferenced": false, "noEngineReferences": false }
```
```json
{ "name": "Game.Tests.EditMode", "rootNamespace": "Game.Tests", "references": ["Game.Core", "UnityEngine.TestRunner", "UnityEditor.TestRunner"],
  "includePlatforms": ["Editor"], "overrideReferences": true, "precompiledReferences": ["nunit.framework.dll"],
  "defineConstraints": ["UNITY_INCLUDE_TESTS"], "autoReferenced": false }
```

_Cameras

## Agent tooling (decided from research, see docs/research/11)
- **Official Unity plugin for Claude Code** (technical Unity skills + `unity-cli`): `/plugin marketplace add Unity-Technologies/unity-agent-plugin` then `/plugin install unity@unity-agent-plugin`. v3 does not duplicate its technical content.
- **Bridge:** official Unity CLI / `unity mcp` first. Register MCP per project only (`claude mcp add --scope local ...`), never globally. Pin the pipeline package version in `Packages/manifest.json`.
- **Fallback bridge** if custom tool registration is needed: IvanMurzak/Unity-MCP (`[AiTool]` attribute). CoplayDev/unity-mcp if an older Unity version is required.
- **Known pitfalls:** domain reload restarts bridges (retry once); compile errors block the bridge (fix C# first); modal dialogs block everything (start Editor with `-automated` for unattended work); an unfocused Editor may stop ticking; do not install the AI Assistant package only for MCP on Unity 6.0.5–6.5 (reported deadlock); IvanMurzak requires a project path without spaces.
- **Test our path:** this repository's path contains non-ASCII characters (`oyungeliştirme`) — verify the chosen bridge and batchmode work with it before relying on them; otherwise put the Unity project under an ASCII path.

## Recommended packages
- Unity Test Framework (built in), AI Navigation (for critical-path measurement).
- Optional: Test Helper / UI Test Helper (nowsprinting) for screenshot and UI operation helpers.

## Setup checklist
- [ ] `.gitignore` and `.gitattributes` from this template at project root
- [ ] `git lfs install`; UnityYAMLMerge driver configured
- [ ] Force Text + Visible Meta Files
- [ ] Official Unity plugin installed in Claude Code
- [ ] Bridge connected: `claude mcp list` shows it; a read-only call (editor status / console) works
- [ ] Path check: bridge + batchmode + offline `dotnet build` all work in this project path
- [ ] Folders and asmdefs created via the bridge (Unity writes the `.meta` files)
- [ ] One passing EditMode test; `/unity-test` reports it
- [ ] v3 review tools compiled; `Tools/Review/*` menu items run on an empty scene
- [ ] v3 files copied: `.claude/`, `CLAUDE.md`, `game/`, `memory/`, `evals/`
