# Feature Maturity Levels

| Level | Meaning | Minimum evidence |
|---|---|---|
| M0 IDEA | Unvalidated concept | Problem/hypothesis |
| M1 EXPERIMENTAL | Disposable experiment | Spike result |
| M2 FUNCTIONAL | Happy path works locally | Functional evidence |
| M3 INTEGRATED | Works with dependent systems | Integration evidence |
| M4 VALIDATED | Acceptance criteria and target scenarios pass | Evidence pack |
| M5 PRODUCTION READY | Quality attributes, failure, performance, platform, docs pass | Independent acceptance |
| M6 FROZEN | Accepted baseline protected by change control | Freeze record and revision |

“Exists” is not a maturity level. Labels apply to a specific revision and environment.
