## What it does

Only owner-policy mode changes; everything without a policy behaves as today.

- **New controlled file `.claude/hooks/policy_lib.py`** (controlled through `.claude/hooks/**`): lane matching on concrete paths (casefolded, `./` stripped), a built-in deny list (Editor folders, `Assets/Plugins`, `Packages`, `ProjectSettings`, `.asmdef`/`.asmref`/`.dll`/`.rsp`, `.git*`) merged with the policy's `deny_paths` and `CONTROLLED_PATHS`, secret path and content patterns, the C# scan, the daily lease counter, the activation rules, the write-time rules, and the seal-time checks.
- **`govern_write.py`, write time:** for an owner-policy lease, every write inside the lease is checked with the same path rules (deny list, extension list, lane, unsafe path), and the written `content`, `new_string`, or `new_source` is scanned for C# problems, secrets, and long encoded runs. A forbidden file can no longer be written and left behind to jam the lease.
- **Revocation:** `load_lease` refuses an owner-policy lease when the policy file is missing, invalid, or has a different hash from the one recorded at activation. Deleting or editing the policy stops the lease at once (writes, shell allowances, seal).
- **`activate_lease.py --owner-policy`:** no prompts; refuses `--inherit-dirty`; hours default to the policy limit (also for the `--hours=N` form) and may not exceed it; the task must be inside exactly one lane, on the policy branch, rigor within `min(lane cap, policy cap)`, `approval_mode: hash`, `approved_by` in `reviewer_ids` and `authored_by` outside it, empty `allowed_commands` (or listed in the policy), a non-blank valid `commit_subject` (charset, no AI attribution), and under the daily limit. The lease records `authority`, `policy_id`, `policy_sha256`, `lane`, and `commit_subject`; human leases now record `authority: human`.
- **`seal_implementation.py` for an owner-policy lease:** per changed file: lane, extension list, deny list, path safety; every file's bytes are scanned for secrets (also `x.png` text payloads; PNG magic is checked); NUL bytes in text files (UTF-16) and non-UTF-8 C# are refused; C# is scanned; long base64 or hex runs are refused; size and count limits; no ignored file inside the lane; unique `.meta` GUIDs.
- **The C# scan** (a speed bump, not a sandbox) checks the raw text and a comment-stripped copy: allowed `using` namespaces anywhere in the text (not only at line starts), qualified names (`System.<allowed members>` only; `Microsoft.`, `Mono.`, `Windows.` refused), `using static`/alias/`global using`, and banned tokens (unicode escapes `\u`/`\U`, `unsafe`, `extern`, `#if`, `#define`, `AppDomain`, `Assembly`, `dynamic`, `Base64`, reflection, `System.IO`, `System.Net`, `Process`, `PlayerPrefs`, `Application.OpenURL`, `UnityEditor`, `InitializeOnLoad`, `DllImport`, ...).
- **`common.py`:** `.git/**` becomes a controlled path; a `main` branch policy is accepted only with `commit_to_default_branch: true`, `base_branch: main`, `remote_name: origin`, an ASCII `https://` `remote_url` without credentials or `..`, and `max_unpushed_commits`; `effective_rigor_cap` and lane `max_rigor` may not exceed `R2` (R3 and R4 always need the owner).
- **`validate_os.py`:** unit tests of the library (including the evasions), main-branch and rigor-cap policy tests, and an end-to-end test in a fresh temporary Git repository (a copy of the working tree without `.git`, so it also works from a linked worktree): activation without prompts and its refusals, the daily limit, write-hook decisions, policy deletion and restoration, and the seal refusals and a successful seal. The two existing temporary copies also skip `owner-policy.json`, `lease-counter.json`, and `empty-hooks`.

## Known limits

- Nothing was executed by the author or any reviewer; the new tests are the first real run.
- The C# scan and the secret scan are speed bumps and can be evaded (for example by string-built reflection).
- The C# rule is deliberately strict: in owner-policy lanes any `//` that is not a whole-line comment is refused (so trailing comments and string literals such as `"https://…"` are refused), `/*` is refused everywhere, and any line starting with `#` (after stripping leading whitespace) is refused, including a verbatim (`@"..."`) string whose line happens to start with `#`. Code written for these lanes must keep comments on their own lines, avoid `//` and leading `#` inside strings, and avoid preprocessor directives; the owner can lift this per task by working outside the policy lanes.
- The secret content scan reads whole changed files, not only added lines, so an old secret in a modified file is flagged too.
- The daily counter reads a corrupt file as zero; only the controlled script can write it.
- Entropy checks are not implemented. A lane segment starting with `git` (after stripping dots) is refused by Patch A's validation.
