# Bug Management

Severity:

- `P0`: data loss, security/authority breach, unrecoverable blocker, release unusable.
- `P1`: core loop, multiplayer, save, major performance, or common softlock failure without acceptable workaround.
- `P2`: material defect with workaround or limited scope.
- `P3`: minor/cosmetic issue.

Each bug records environment, revision, exact reproduction, expected/actual, frequency, impact, artifacts, and regression acceptance. Closing requires fix evidence at a named revision. “Could not reproduce once” is not closure.
