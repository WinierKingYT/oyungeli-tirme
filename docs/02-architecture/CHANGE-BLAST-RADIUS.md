# Change Blast Radius Method

For every R2+ task inspect:

- canonical state and writers;
- dependent gameplay systems;
- interfaces, events, and public APIs;
- networking and authority;
- save data and migrations;
- UI, audio, animation, VFX, and accessibility;
- assets, levels, missions, and content references;
- tests, debug scenarios, telemetry, and tools;
- performance, memory, allocation, and bandwidth;
- build, packaging, target platforms, and release compatibility.

The task contract lists affected areas as `IN_SCOPE`, `VALIDATE_ONLY`, `NOT_AFFECTED_WITH_EVIDENCE`, or `UNKNOWN`.
