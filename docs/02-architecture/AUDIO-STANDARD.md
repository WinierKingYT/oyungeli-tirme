# Audio Standard

Status: `PROPOSED`

Define event naming, ownership, spatialization, attenuation, concurrency, priority, occlusion, mixing, dynamic range, platform compression, localization, accessibility cues, network triggering, save implications, and performance budget.

Gameplay-critical audio has a visual or haptic alternative where required. Repeated machine/ship sounds require concurrency and fatigue review. Audio events must not become hidden gameplay state owners.
