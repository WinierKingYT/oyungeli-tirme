# UI and UX Standard

Status: `PROPOSED`

The ship game favors world-local information and a minimal persistent HUD. UI presents domain state through accepted query boundaries; it does not own gameplay truth.

Every interaction defines affordance, focus/input mode, controller and keyboard/mouse behavior, feedback, error/recovery, latency state, localization, text scaling, color-independent cues, subtitle/caption needs, and multiplayer ownership.

Acceptance includes target resolution/aspect ratios, input devices, readable states, failure feedback, and accessibility checks.
