# Game Pillars

Status: `PROPOSED`

1. **Physical cooperation:** players handle, secure, repair, navigate, and communicate through readable physical actions.
2. **Emergent voyages:** cargo, weather, failures, markets, and incomplete recovery create different stories.
3. **Readable ship world:** information appears near the system that owns it; minimal persistent HUD.
4. **Meaningful imperfection:** not every crisis must be solved, but consequences remain legible and recoverable.
5. **Simple production language:** stylized, performant characters and assets support iteration and cosmetics.
