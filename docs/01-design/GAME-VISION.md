# Game Vision

Status: `DISCOVERY_INPUT`

A cooperative maritime cargo-and-repair game in which players move a working ship from port A through several islands to port B, making trade, loading, navigation, maintenance, and crisis decisions. Physical cargo, limited services, imperfect information, escalating failures, and quiet travel activities create stories without requiring constant combat or a permanent HUD.

This vision is derived from design discussion and must be ratified in the real project.
