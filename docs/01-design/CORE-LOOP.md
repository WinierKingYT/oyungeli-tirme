# Core Loop

Status: `PROPOSED`

`Choose route/cargo -> load and secure -> depart -> navigate and maintain -> react to crises -> visit islands -> trade/repair/refuel -> arrive -> unload/sell -> upgrade/prepare -> repeat`

## Required validation questions

- Is loading and securing cargo interesting before crisis systems exist?
- Does travel contain enough active choice without becoming constant chores?
- Can failure create recovery stories instead of softlocks?
- Does multiplayer cooperation improve decisions rather than only increase labor?
- Are trade and mission rewards understandable without a spreadsheet UI?
